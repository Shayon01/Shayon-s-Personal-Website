# Shayon Shandilya — Personal Website

A responsive, editorial-style personal portfolio and knowledge journal. Built with HTML, CSS, and vanilla JavaScript so it is simple to edit and deploy.

## Included
- Personal introduction and about section
- Selected projects
- Three learning categories: Product Management, FinTech, and Science
- Filterable starter reading list
- Professional journey and resume section
- Contact links
- Responsive mobile navigation and reading progress indicator

## Preview locally
Open `index.html` in your browser. For a local development server, use the Live Server extension in VS Code.

## Add your resume
Place your latest PDF in `assets/` and name it `Shayon-Shandilya-Resume.pdf`. The resume download button already points to that path.

## Personalise before publishing
1. Replace the generic LinkedIn link in `index.html` with your exact profile URL.
2. Check all project descriptions and dates for accuracy.
3. Add project demo links where available.
4. Add full tutorials as dedicated pages when ready. The current reading list is a topic index, not completed article content.
5. Review the public details for confidentiality before publishing.

## Update the journal topics
Edit `assets/js/content.js`. Each item has a category (`product`, `fintech`, or `science`), title, description, label, reading time, and number.

## Deploy
This is a static website and can be hosted on Netlify, GitHub Pages, or another static host. Upload the files while preserving the folder structure. The homepage file must remain `index.html` at the published site's root.

If replacing an existing site, keep a backup of the current files first.
